# 런메이트 (RunMate)

뛰거나 걸으면 경로와 거리를 기록하고, **걷기와 뛰기를 자동으로 나눠** 보여 주는 안드로이드 러닝 앱입니다. (v0.3 기준)

- 설치 파일: [Releases](https://github.com/sby1234-ai/runmate/releases/latest)
- 웹 화면(GPX 기록 보기): https://sby1234-ai.github.io/runmate/

## 할 수 있는 것

### 기록
- **기록 시작·정지**: 시작을 누르면 바로 기록합니다. 실수로 멈추지 않도록 정지는 길게 누릅니다.
- **걷기·뛰기 자동 구분**: 휴대폰의 동작 인식(걷기·뛰기·멈춤)과 걸음 센서의 케이던스(분당 140걸음 이상이면 뛰기)를 먼저 쓰고, GPS 속도로 보정합니다. 동작 인식 권한이 없으면 속도만으로 구분합니다(기준 2.2 m/s ≈ 1km 7분 35초).
- **걸음 수·케이던스**: 휴대폰 걸음 센서로 걸음 수와 분당 걸음을 기록합니다.
- **GPS 흔들림 거르기**: 멈춰 있을 때 GPS 점이 흔들려 거리가 늘어나는 것을 걸러 냅니다. 정확도 설명과 다른 앱과 비교하는 방법은 [`docs/ACCURACY.md`](docs/ACCURACY.md).
- **자동 일시정지**: 5초 넘게 멈춰 있으면 운동 시간을 멈추고, 다시 움직이면 이어서 잽니다.
- **음성 안내**: 1km마다 거리와 방금 1km에 걸린 시간, 운동 시간을 읽어 줍니다. 걷기↔뛰기가 15초 넘게 바뀐 상태로 이어지면 알려 줍니다.
- **인터벌 코칭**: 「1분 뛰기 / 2분 걷기 × 6」처럼 뛰기와 걷기를 번갈아 하는 프로그램 4가지. 일시정지하면 인터벌 시간도 멈춥니다.

### 화면이 꺼져도, 앱이 꺼져도
- **백그라운드·잠금 상태 기록**: 기록 중에는 알림을 띄운 채로 돌아서, 화면을 끄고 주머니에 넣어도 기록이 이어집니다. 앱 화면과 알림의 시간은 같은 기준점이라 초까지 일치합니다.
- **알림 카드**: 어두운 카드에 흐르는 운동 시간, 거리, 몇 km째와 구간 페이스를 보여 주고, 「일시정지/계속」·「종료」 버튼이 있습니다. 「종료」를 누르면 앱이 열리며 결과 화면이 나옵니다. 기록 중에는 알림을 밀어서 지워도 다시 나타납니다.
- **잠금 화면**: 잠금 화면에는 알림 카드가 보입니다(갤럭시는 설정 → 잠금화면 및 AOD → 잠금화면 알림 → 알림 스타일 「카드」일 때). 설정에서 켜면 화면을 다시 켤 때 잠금 위에 달리기 화면이 바로 나옵니다(잠금이 풀린 것처럼 보일 수 있어 기본은 꺼짐).
- **강제 종료 뒤 이어서 기록**: 휴대폰이 앱을 강제로 끄더라도 10초마다 저장해 둔 중간 기록에서 이어서 기록합니다.
- **상태 표시줄 칩(안드로이드 16 분기 업데이트 이상)**: 안드로이드 16의 「실시간 알림」을 요청해 상태 표시줄 초록 칩에 거리를 보여 줍니다. 안드로이드 16.0 정식판은 이 기능이 다른 앱에 열려 있지 않아 칩이 나오지 않고, 휴대폰이 업데이트되면 앱 수정 없이 나옵니다. 갤럭시 나우 바는 삼성이 등록한 앱만 들어갈 수 있어 런메이트는 나오지 않습니다.

### 화면
- **날씨에 따라 바뀌는 첫 화면**: 맑음·흐림·비·눈·밤 등 지금 날씨에 맞는 어두운 배경, 달리는 중 움직이는 러너.
- **기록 보기**: 어두운 지도 위 경로(뛰기 주홍·걷기 청록·멈춤 회색), 1km 구간 막대, 뛴 거리·걸은 거리, 가장 빠른 1km, 걸음 수.
- **기록 모아 보기**: 이번 주·이번 달 거리, 최고 기록(가장 빠른 1km·5km·10km, 가장 긴 거리).
- **이미지로 공유**: 거리·시간·페이스·뛰기 비율과 길 모양을 세로 이미지(1080×1350)로 만들어 보냅니다. 집 위치가 드러나지 않게 지도 그림은 넣지 않습니다.
- **GPX 내보내기**: 다른 러닝 앱이나 지도 서비스로 옮길 수 있게 GPX 파일로 보냅니다.
- **자동 업데이트**: 하루 한 번 새 버전을 확인하고, 받은 파일의 SHA-256을 확인한 뒤 설치 화면을 엽니다(설치는 사용자가 「설치」를 눌러야 함). 설정에서 끌 수 있습니다.

## 개인정보와 보안

- **기록은 인터넷으로 보내지 않습니다.** 기록을 업로드하는 코드도, 계정이나 서버도 없습니다. 기록은 앱 전용 폴더에만 저장되어 다른 앱이 읽을 수 없고, 백업에도 포함하지 않습니다(`allowBackup=false`).
- **인터넷을 쓰는 곳은 세 군데뿐입니다.**
  - 지도 그림: OpenStreetMap 재단의 지도 서버(`tile.openstreetmap.org`)에 화면에 띄운 지역의 지도 조각을 요청합니다. 설정에서 지도를 끄면 지도 라이브러리를 만들지 않아 요청이 생기지 않습니다.
  - 날씨: Open-Meteo(`api.open-meteo.com`)에 소수 첫째 자리까지만 줄인 위치(약 10km 단위)를 보내 현재 날씨를 받습니다. 설정에서 끌 수 있습니다.
  - 업데이트 확인: GitHub(`api.github.com`)에서 이 저장소의 최신 릴리스 정보만 받습니다. 설정에서 끌 수 있습니다.
- 받아 둔 지도 조각은 앱 캐시 폴더에만 두며, 설정의 「받아 둔 지도 지우기」로 지울 수 있습니다.
- 요청하는 권한: 위치(정확한 위치), 신체 활동(걷기·뛰기 인식, 걸음 수), 알림(기록 중 표시), 포그라운드 서비스(위치), 화면 깨우기·배터리 최적화 제외 요청(기록이 끊기지 않게), 전체 화면 알림(잠금 위 달리기 화면), 실시간 알림(상태 표시줄 칩), 앱 설치 요청(업데이트 설치 화면), 인터넷. 위치는 「앱 사용 중에만 허용」이면 충분합니다. 빌드할 때마다 이 목록 밖의 권한이 섞여 들어오면 빌드를 실패시킵니다.
- 설치 파일 서명 키는 저장소에 없고 GitHub Secrets에만 있습니다. 공식 설치 파일은 이 저장소의 Releases에서만 받으세요.

## 설치

1. 이 저장소의 **Releases**에서 `runmate-버전.apk`를 휴대폰으로 받습니다.
2. 파일을 누르고 「출처를 알 수 없는 앱 설치」를 허용해 설치합니다. Play 프로텍트가 「유해한 앱 차단됨」을 띄우면 「무시하고 설치」를 누릅니다(Play 스토어에 등록되지 않은 앱이라 나오는 경고). 설치 후 출처 허용은 다시 꺼 두세요.
3. 처음 시작할 때 위치·신체 활동·알림 권한을 허용하고, 첫 화면 안내대로 배터리 최적화에서 「런메이트」를 제외합니다(갤럭시: 「제한 없음」).
4. 이후 새 버전은 앱이 알려 줍니다.

## 만드는 방법

- 안드로이드 16 기준(compileSdk·targetSdk 36, minSdk 26), Kotlin, Android Gradle Plugin 8.10.1.
- `main`에 올리면 GitHub Actions가 단위 테스트를 돌리고 APK를 만듭니다(`.github/workflows/build.yml`). 결과는 `ci-logs` 브랜치.
- `app/**`이 바뀌면 에뮬레이터(안드로이드 14·16)에서 화면을 찍어 `ci-screens`·`ci-screens36` 브랜치에 올립니다(`.github/workflows/screens.yml`).
- `app/build.gradle.kts`의 `versionName`을 올려 `main`에 반영하면, 그 버전의 서명된 APK와 SHA-256 값을 Releases에 자동으로 올립니다.
- 직접 빌드: Android Studio로 열거나, JDK 17과 Gradle 8.11.1 이상에서 `gradle testDebugUnitTest assembleDebug`.

| `app/src/main/java/.../logic/` | 걷기·뛰기 구분(`MotionClassifier`), 거리·구간 계산(`RunStats`), GPS 흔들림 거르기(`Smoother`), 걸음(`Steps`), 인터벌(`Interval`), 자동 일시정지(`Pause`), 음성 안내 문구(`Coach`), 최고 기록·주간 합계(`Records`), 중간 저장(`Checkpoint`), 날씨(`Weather`), 업데이트 판단(`Update`), GPX(`Gpx`) — 안드로이드와 무관한 순수 로직 |
| `app/src/test/` | 위 로직의 단위 테스트 |
| `RecordingService.kt` | 알림을 띄운 채 도는 기록 서비스(GPS, 동작 인식, 걸음, 알림 카드·실시간 알림, 강제 종료 복구) |
| `RunRecorder.kt` | 기록 상태와 시간 기준점(앱·알림 공통) |
| `LiveNotif.kt` | 안드로이드 16 실시간 알림 지원 여부·안내 |
| `Updater.kt` | 자동 업데이트(확인·받기·SHA-256 확인·설치 화면) |
| `data/` | 기록 저장(앱 전용 폴더의 JSON), 중간 저장, 설정, 날씨 캐시 |
| `ui/` | 지도(`MapPanel`, osmdroid), 경로 그림, 날씨 배경(`SkyView`), 러너, 공유 이미지(`ShareImage`), 전체 화면 여백(`EdgeInsets`) |
| `Voice.kt` | 휴대폰 음성 합성으로 안내 읽기 |
| `web/` | GPX 기록을 웹에서 보는 화면(GitHub Pages) |
| `docs/` | 계획서(`plan.md`), 정확도(`ACCURACY.md`), 작업 인계(`HANDOFF.md`) |
