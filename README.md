# 런메이트 (RunMate)

뛰거나 걸으면 경로와 거리를 기록하고, **걷기와 뛰기를 자동으로 나눠** 보여 주는 안드로이드 러닝 앱입니다.

## 할 수 있는 것

- **기록 시작·정지**: 시작을 누르면 바로 기록합니다. 실수로 멈추지 않도록 정지는 길게 누릅니다.
- **화면이 꺼져도 기록**: 기록 중에는 알림을 띄운 채로 돌아서, 휴대폰을 주머니에 넣어도 GPS 기록이 이어집니다.
- **걷기·뛰기 자동 구분**: 휴대폰의 동작 인식(걷기·뛰기·멈춤)을 먼저 쓰고, GPS 속도로 보정합니다. 동작 인식 권한을 주지 않으면 속도만으로 구분합니다(기본 기준 2.2 m/s ≈ 1km 7분 35초).
- **지도**: 달리는 동안 지나간 길을 OpenStreetMap 지도 위에 뛰기 주홍·걷기 청록·멈춤 회색으로 그립니다. 설정에서 끌 수 있고, 끄면 지도 없이 길 모양만 그립니다.
- **음성 안내**: 1km마다 거리와 방금 1km에 걸린 시간, 운동 시간을 읽어 줍니다. 걷기↔뛰기가 15초 넘게 바뀐 상태로 이어지면 알려 줍니다. 음악은 잠깐 소리를 줄였다가 되돌립니다.
- **자동 일시정지**: 5초 넘게 멈춰 있으면 운동 시간을 멈추고, 다시 움직이면 이어서 잽니다.
- **인터벌 코칭**: 「1분 뛰기 / 2분 걷기 × 6」처럼 뛰기와 걷기를 번갈아 하는 프로그램 4가지. 차례가 바뀔 때마다 음성으로 알려 주고 화면에 남은 시간을 보여 줍니다.
- **기록 모아 보기**: 이번 주·이번 달 거리, 최고 기록(가장 빠른 1km·5km·10km, 가장 긴 거리). 기록 화면에서 이 기록이 최고 기록이면 표시합니다.
- **기록 보기**: 지도, 1km 구간 막대(가장 빠른 구간 강조), 뛴 거리·걸은 거리, 가장 빠른 1km.
- **이미지로 공유**: 거리·시간·페이스·뛰기 비율과 길 모양을 세로 이미지로 만들어 메신저나 SNS로 보냅니다. 집 위치가 드러나지 않게 지도 그림은 넣지 않습니다.
- **GPX 내보내기**: 다른 러닝 앱이나 지도 서비스로 옮길 수 있게 GPX 파일로 보냅니다.

## 개인정보와 보안

- **기록은 인터넷으로 보내지 않습니다.** 앱에 기록을 업로드하는 코드도, 계정이나 서버도 없습니다. 기록은 앱 전용 폴더에만 저장되어 다른 앱이 읽을 수 없고, 백업에도 포함하지 않습니다(`allowBackup=false`).
- **인터넷은 지도 그림을 받을 때만 씁니다.** 지도를 켜 두면 OpenStreetMap 재단의 지도 서버(`tile.openstreetmap.org`)에 화면에 띄운 지역의 지도 조각을 요청하므로, 그 서버는 어느 지역 지도를 봤는지 알 수 있습니다. 이것이 싫으면 설정에서 지도를 끄세요. 끄면 지도 라이브러리를 아예 만들지 않아 인터넷 요청이 생기지 않습니다.
- 받아 둔 지도 조각은 앱 캐시 폴더에만 두며, 설정의 「받아 둔 지도 지우기」로 지울 수 있습니다.
- 요청하는 권한: 위치(정확한 위치), 신체 활동(걷기·뛰기 인식), 알림(기록 중 표시), 인터넷(지도). 위치는 「앱 사용 중에만 허용」이면 충분합니다. 빌드할 때마다 이 목록 밖의 권한이 섞여 들어오면 빌드를 실패시킵니다.
- 설치 파일 서명 키는 저장소에 없고 GitHub Secrets에만 있습니다. 공식 설치 파일은 이 저장소의 Releases에서만 받으세요.

## 설치

1. 이 저장소의 **Releases**에서 `runmate-버전.apk`를 휴대폰으로 받습니다.
2. 파일을 누르고 「출처를 알 수 없는 앱 설치」를 허용해 설치합니다. 설치 후 그 허용은 다시 꺼 두세요.
3. 처음 시작할 때 위치·신체 활동·알림 권한을 허용하고, 첫 화면 안내대로 배터리 최적화에서 「런메이트」를 제외합니다(갤럭시: 「제한 없음」).

## 만드는 방법

- `main`에 올리면 GitHub Actions가 단위 테스트를 돌리고 APK를 만듭니다(`.github/workflows/build.yml`).
- `app/build.gradle.kts`의 `versionName`을 올려 `main`에 반영하면, 그 버전의 서명된 APK와 SHA-256 값을 Releases에 자동으로 올립니다.
- 직접 빌드: Android Studio로 열거나, JDK 17과 Gradle 8.7 이상에서 `gradle testDebugUnitTest assembleDebug`.

## 구조

| 위치 | 내용 |
|---|---|
| `app/src/main/java/.../logic/` | 걷기·뛰기 구분(`MotionClassifier`), 거리·구간 계산(`RunStats`), 인터벌(`IntervalPlan`), 자동 일시정지(`PauseTracker`), 음성 안내 문구(`Coach`), 최고 기록·주간 합계(`Records`), GPX(`Gpx`) — 안드로이드와 무관한 순수 로직 |
| `app/src/test/` | 위 로직의 단위 테스트 |
| `RecordingService.kt` | 알림을 띄운 채 도는 기록 서비스(GPS, 동작 인식) |
| `data/RunStore.kt` | 기록 저장(앱 전용 폴더의 JSON) |
| `ui/MapPanel.kt` | 지도(osmdroid) 또는 지도 없는 길 그림 |
| `Voice.kt` | 휴대폰 음성 합성으로 안내 읽기 |
