[1차 이후 달라진 것]
0.2 — 다른 러닝 앱(나이키런클럽·스트라바·런키퍼·런데이)과 비교해 보강
- 지도(OpenStreetMap, 설정에서 끄면 인터넷 요청 없음), 1km마다 음성 안내, 자동 일시정지, 인터벌 코칭 4종
- 이번 주·이번 달 합계와 최고 기록(가장 빠른 1km·5km·10km, 가장 긴 거리), 기록 이미지 공유(집 위치가 드러나지 않게 지도 없이 길 모양만)

0.3 — 목표를 "삼성 헬스와 나란히 써도 뒤지지 않게"로 올리고 휴대폰으로 직접 확인하며 고침
- 화면: 지금 날씨에 따라 바뀌는 어두운 첫 화면, 달리는 중 움직이는 러너, 기록 보기의 어두운 지도
- 기록: 화면이 꺼지거나 잠겨도 이어서 기록, 걸음 수·케이던스(분당 140걸음 이상이면 뛰기), GPS 흔들림 거르기, 몇 km째·구간 페이스
- 시간: 앱 화면과 알림의 초가 어긋나던 것을 시계 하나로 통일, 일시정지 시간 계산 버그 수정
- 안정성: 휴대폰이 앱을 강제로 꺼도 10초마다 중간 저장해 둔 곳부터 이어서 기록
- 알림: 어두운 카드에 흐르는 운동 시간·거리, 「일시정지/계속」「종료」 버튼, 「종료」 뒤 결과 화면 열림, 밀어서 지워도 다시 나타남
- 자동 업데이트: 하루 한 번 새 버전 확인 → 받은 파일 SHA-256 확인 → 설치 화면(설치는 사용자가 누름)
- 안드로이드 16 기준으로 빌드(상태 표시줄 칩용 실시간 알림 준비, 모든 화면 여백 맞춤)

[확인한 방법]
- 단위 테스트: 걷기·뛰기 구분, 거리·구간, GPS 흔들림 거르기, 걸음, 음성 안내, 인터벌, 자동 일시정지, 최고 기록, 중간 저장, 날씨, 업데이트 판단, GPX — 실패하면 설치 파일이 만들어지지 않음
- 권한 점검: 빌드마다 권한 목록을 뽑아 허용 목록 밖의 권한이 섞이면 빌드 실패
- 에뮬레이터 자동 점검(안드로이드 14·16): 가상 위치로 실제 기록을 돌려 화면·잠금 화면·알림·일시정지·앱과 알림 시간 일치·종료 뒤 결과 화면·공유 이미지를 캡처
- 실제 휴대폰(갤럭시, One UI 8.0 / 안드로이드 16.0): 덮어 설치하며 단계마다 확인

[막힌 것과 결론]
- 상태 표시줄 초록 칩·나우 바: 안드로이드 16.0 정식판은 실시간 알림이 다른 앱에 열려 있지 않음을 에뮬레이터로 확인(권한이 정의돼 있지 않아 항상 꺼짐). 나우 바는 휴대폰 설정의 「실시간 정보」 목록을 보니 삼성이 등록한 앱만 들어감. 앱이 해결할 수 없는 부분이라, 칩은 휴대폰이 업데이트되면 자동으로 나오도록 코드만 준비하고 마무리.
- 잠금 화면에 카드가 안 보임: 휴대폰의 잠금화면 알림 스타일이 「아이콘」이었기 때문. 「카드」로 바꾸면 보이는 것을 직접 확인.

[AI와 내 판단 3줄]
1. 잠금 화면에 카드가 안 보일 때 AI는 알림 스타일 설정을 원인으로 봤고, 나는 "삼성 헬스는 아이콘 형식에서도 뜬다"며 다시 따졌다. 직접 「카드」로 바꿔 확인해 원인을 확정했다.
2. 그 설정을 바꾸라고 사용자에게 안내할지 정할 때, 다른 사람의 휴대폰 전체 설정을 바꾸게 하는 건 맞지 않다고 판단해 강요하지 않고 설정 화면에 선택 사항으로만 적었다.
3. 나우 바·초록 칩은 원인이 휴대폰 쪽(안드로이드 16.0, 삼성 등록 앱 제한)으로 확인되자 더 붙잡지 않고 마무리하고, 남은 시간을 실사용 확인과 최종 제출에 쓰기로 했다.
