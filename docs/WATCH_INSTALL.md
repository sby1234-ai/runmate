# 워치 앱 설치 (윈도우 PC, 무선 adb)

갤럭시 워치4 이후·픽셀 워치 등 **Wear OS 3 이상**에 설치됩니다. (타이젠 워치3·액티브2는 불가)
휴대폰에도 같은 릴리스의 런메이트(`runmate-vX.apk`)가 깔려 있어야 연결됩니다.

## 1. 한 번만 준비

1. PC에 **SDK Platform-Tools** 받기: https://developer.android.com/tools/releases/platform-tools → 「Download SDK Platform-Tools for Windows」 → 압축을 `C:\platform-tools` 에 풉니다.
2. 워치 개발자 옵션 켜기: 워치 **설정 → 워치 정보 → 소프트웨어 정보 → 소프트웨어 버전** 을 7번 누름.
3. 워치 **설정 → 개발자 옵션** 에서 **ADB 디버깅** 켜기 → **무선 디버깅** 켜기.
4. PC와 워치가 **같은 와이파이**에 있어야 합니다(워치 설정 → 연결 → 와이파이).

## 2. 설치 (PowerShell)

워치 **무선 디버깅 → 새 기기 페어링** 화면에 나온 「IP:포트」와 「코드」를 씁니다.

```powershell
cd C:\platform-tools

# 1) 페어링: 「새 기기 페어링」 화면의 IP:포트 → 코드 입력
.\adb pair 192.168.0.23:41235

# 2) 연결: 「무선 디버깅」 첫 화면의 IP:포트 (페어링 포트와 다름)
.\adb connect 192.168.0.23:37099

# 3) 확인용: 워치가 device 로 보이면 성공
.\adb devices

# 4) 설치: 릴리스에서 받은 워치용 파일
.\adb install -r "$env:USERPROFILE\Downloads\runmate-wear-v0.5.1.apk"
```

- 위 IP·포트·파일 이름은 예시입니다. 자기 화면에 나온 값으로 바꾸세요.
- 페어링(1)은 처음 한 번만. 다음부터는 2)~4)만 하면 됩니다(포트는 매번 바뀔 수 있음).
- 새 버전도 같은 명령(4)으로 덮어 설치됩니다.

## 3. 쓰는 법

- 워치 앱 목록에서 **런메이트** 실행 → 「시작」.
  - 휴대폰 런메이트 첫 화면이 열려 있으면 바로 3·2·1 후 기록 시작.
  - 휴대폰 화면이 꺼져 있거나 다른 앱이면 휴대폰에 「워치에서 시작」 알림이 뜹니다 → 눌러서 시작(안드로이드가 백그라운드에서 위치 기록을 바로 못 켜게 막기 때문).
- 처음 「시작」을 누르면 워치가 **신체 센서(심박)** 권한을 묻습니다 → 허용.
- 기록 중: 시간·거리·걷기/뛰기·심박 표시, 「일시정지/계속」, 「종료」는 **길게** 누름.
- 심박은 기록 중 5초마다 휴대폰에 저장되고, 기록 상세의 심박 카드에 나옵니다.

## 4. 안 될 때

| 증상 | 확인 |
| --- | --- |
| `adb devices` 에 안 보임 | 같은 와이파이인지, 무선 디버깅이 켜져 있는지, `adb connect` 포트를 다시 확인 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 다른 서명의 런메이트가 워치에 있음 → `.\adb uninstall io.github.sby1234ai.runmate` 후 다시 설치 |
| 워치에 「휴대폰 런메이트를 찾는 중…」 | 휴대폰에 같은 릴리스 런메이트가 있는지, 갤럭시 웨어러블 앱으로 워치가 연결돼 있는지 |
| 심박이 안 나옴 | 워치 설정 → 애플리케이션 → 런메이트 → 권한 → 신체 센서 허용 |
