# 정확도: 어떻게 재고, 다른 앱과 어떻게 비교하나

## 런메이트가 쓰는 센서와 방법

| 항목 | 쓰는 것 | 다른 앱(삼성 헬스·나이키 런 클럽)과 같은가 |
|---|---|---|
| 거리·경로 | 휴대폰 GPS(구글 위치 서비스, 고정밀, 2초마다) → 흔들림 거르기(칼만 필터) → 멈춘 구간 제외 | 같은 GPS를 쓰고, 흔들림을 거르는 방식도 같은 종류 |
| 걸음 수 | 휴대폰 하드웨어 걸음 센서(`TYPE_STEP_COUNTER`) | 같은 센서 |
| 걷기·뛰기 | ① 휴대폰 동작 인식(구글) ② 분당 걸음 140 이상이면 뛰기 ③ GPS 속도(1km 7분 35초 기준) | 다른 앱은 보통 걷기·뛰기를 나누지 않음(런메이트의 차별점) |
| 시간 | 기기 경과 시계(`elapsedRealtime`) 하나로, 앱 화면·잠금 화면이 같은 기준점 | 같은 방식 |

자이로 센서는 회전을 재는 센서라 걸음 수·거리 정확도에는 거의 도움이 되지 않아 쓰지 않습니다(걸음 센서는 가속도계 기반).

## 확인한 것 (자동 검사)

- 앱 시간과 상태창(잠금 화면) 시간: 67번 비교해 차이 0번, 초가 건너뛰거나 거꾸로 간 적 0번 (에뮬레이터)
- 일시정지·다시 시작·자동 일시정지를 어떤 순서로 눌러도 운동 시간이 줄지 않음 (무작위 300가지 순서 단위 테스트)
- 제자리에서 흔들리는 GPS(±6m) 2분: 가짜 거리를 40% 넘게 줄임 / 실제로 달린 1,800m는 1,700~1,900m 안에 둠 (단위 테스트)
- 화면이 잠긴 동안에도 기록이 이어짐 (에뮬레이터)

## 직접 비교하는 방법 (삼성 헬스와)

1. 같은 휴대폰에서 **삼성 헬스 「달리기」와 런메이트를 동시에 시작**합니다(두 앱 모두 배터리 최적화 「제한 없음」).
2. 하늘이 트인 곳에서 GPS가 잡힐 때까지(런메이트 「GPS ±○m」가 10m 이하) 기다린 뒤 출발합니다.
3. 2km 이상 걷기와 뛰기를 섞어 달리고, 신호등에서 한 번 멈춰 봅니다.
4. 두 앱을 같이 끝내고 아래 표를 채웁니다.

| 항목 | 삼성 헬스 | 런메이트 | 차이 |
|---|---|---|---|
| 거리 (km) | | | |
| 운동 시간 | | | |
| 걸음 수 | | | |
| 평균 페이스 | | | |

- 거리 차이가 2% 넘게 나면 GPX를 내보내 경로를 비교해 고칩니다(런메이트 기록 화면 → 「GPX로 내보내기」).
- 걸음 수는 같은 센서라 거의 같아야 합니다. 일시정지 중 걸음은 런메이트가 빼므로 그만큼 적을 수 있습니다.
