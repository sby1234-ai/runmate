## 1. 목표

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 휴대폰을 주머니에 넣고 달리면 경로·거리와 함께 걷기·뛰기를 자동으로 나눠 기록하는 안드로이드 러닝 앱 |
| 누구를 위한 것인가 | 달리기를 막 시작해 걷기와 뛰기를 섞어 하는 사람(나와 친구들) |
| 핵심 기능 3가지 | 1. 화면이 꺼져도 이어지는 GPS 기록 2. 걷기·뛰기 자동 구분 3. 기록 보기(경로·1km 구간·뛴 거리/걸은 거리) |
| 완성의 기준 | 나와 친구 2명이 Releases에서 받은 설치 파일로 1주일 동안 각자 3번 이상 실제로 달리고, 기록이 끊기거나 걷기·뛰기가 틀리게 나뉜 곳이 있는지 확인해 고친다 |

## 2. 왜 이 주제인가

- 앞 과제(피싱 링크 확인기)와 상관없이, 누구나 쓸 수 있는 범용 앱을 고르고 싶었다.
- 달리기를 시작하면 대부분 걷기와 뛰기를 섞는데, 흔한 러닝 앱은 이를 한 기록으로 뭉쳐 보여 준다. 걷기·뛰기를 자동으로 나눠 보여 주는 것을 이 앱의 차별점으로 삼는다.

## 3. 결정한 것과 이유

| 결정 | 이유 |
|---|---|
| 웹앱이 아니라 안드로이드 앱 | 웹 페이지는 화면이 꺼지면 GPS 기록이 멈춘다. 달리는 동안 휴대폰은 주머니에 있으므로 백그라운드 기록이 되는 앱이어야 한다. |
| 걷기·뛰기 판단 = 휴대폰 동작 인식 + GPS 속도 | 동작 인식만 쓰면 바뀌는 데 늦고, 속도만 쓰면 GPS가 튈 때 흔들린다. 둘을 합치고 기준(초속 2.2m ≈ 1km 7분 35초)에 여유를 둔다. |
| 기록은 휴대폰 안에만 저장, 서버·계정 없음 | 친구들에게 나눠 줄 앱이라 위치 기록이 밖으로 나가지 않는 것이 가장 안전하다. |
| 빌드는 GitHub Actions에서만 | 내 PC에 안드로이드 개발 도구를 깔지 않아도 되고, 누가 빌드해도 같은 결과가 나온다. 테스트를 통과해야 설치 파일이 만들어진다. |
| 서명 키는 저장소에 넣지 않고 GitHub Secrets에만 | 키가 새면 다른 사람이 가짜 업데이트를 만들 수 있다. 공식 설치 파일은 Releases에서만 받게 하고 SHA-256 값을 함께 올린다. |

## 5. 확인 방법

- 로직(걷기·뛰기 구분, 거리·구간, 인터벌, 자동 일시정지, 최고 기록)은 단위 테스트로 확인하고, 테스트가 실패하면 설치 파일이 만들어지지 않는다.
- 빌드할 때마다 앱 권한 목록을 뽑아, 허용한 권한 밖의 것이 들어오면 빌드를 실패시킨다.
- 실제 GPS·음성·배터리 동작은 휴대폰에서 직접 달리며 확인한다(테스트로 대신할 수 없음).
