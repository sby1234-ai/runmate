# 런메이트 계획 설계서 (plan.md) · v2

- 작성일: 2026-10-29 (v1) · 고친 날: 2026-10-29 (v2)
- 저장소: https://github.com/sby1234-ai/runmate
- 웹 화면: https://sby1234-ai.github.io/runmate/
- 현재 버전: v0.3.12

## 1. 목표

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 휴대폰을 주머니에 넣고 달리면 경로·거리와 함께 걷기·뛰기를 자동으로 나눠 기록하는 안드로이드 러닝 앱 |
| 누구를 위한 것인가 | 달리기를 막 시작해 걷기와 뛰기를 섞어 하는 사람(나와 친구들) |
| 핵심 기능 3가지 | 1. 화면이 꺼져도 이어지는 GPS 기록 2. 걷기·뛰기 자동 구분 3. 기록 보기(경로·1km 구간·뛴 거리/걸은 거리) |
| 수준 목표 (v2에서 추가) | 삼성 헬스·나이키 런 클럽과 나란히 기록했을 때 거리·시간·걸음 수가 뒤지지 않고, 잠금 화면·알림에서도 삼성 헬스처럼 기록을 보고 조작할 수 있을 것 |
| 완성의 기준 | 나와 친구 2명이 Releases에서 받은 설치 파일로 1주일 동안 각자 3번 이상 실제로 달리고, 기록이 끊기거나 걷기·뛰기가 틀리게 나뉜 곳, 다른 앱과 숫자가 크게 다른 곳이 있는지 확인해 고친다 |

## 2. 왜 이 주제인가

- 앞 과제(피싱 링크 확인기)와 상관없이, 누구나 쓸 수 있는 범용 앱을 고르고 싶었다.
- 달리기를 시작하면 대부분 걷기와 뛰기를 섞는데, 흔한 러닝 앱은 이를 한 기록으로 뭉쳐 보여 준다. 걷기·뛰기를 자동으로 나눠 보여 주는 것을 이 앱의 차별점으로 삼는다.

## 3. 결정한 것과 이유

| 결정 | 이유 |
|---|---|
| 웹앱이 아니라 안드로이드 앱 | 웹 페이지는 화면이 꺼지면 GPS 기록이 멈춘다. 달리는 동안 휴대폰은 주머니에 있으므로 백그라운드 기록이 되는 앱이어야 한다. |
| 걷기·뛰기 판단 = 동작 인식 + 걸음 케이던스 + GPS 속도 | 동작 인식만 쓰면 바뀌는 데 늦고, 속도만 쓰면 GPS가 튈 때 흔들린다. v2에서 걸음 센서를 더해 분당 140걸음 이상이면 뛰기로 본다. 기준 속도는 초속 2.2m(≈ 1km 7분 35초). |
| 기록은 휴대폰 안에만 저장, 서버·계정 없음 | 친구들에게 나눠 줄 앱이라 위치 기록이 밖으로 나가지 않는 것이 가장 안전하다. |
| 인터넷은 지도·날씨·업데이트 확인 세 곳만, 각각 끌 수 있게 (v2) | 지도는 지역 지도 조각만, 날씨는 약 10km 단위로 줄인 위치만, 업데이트는 릴리스 정보만 받는다. 기록 자체는 어디로도 보내지 않는다. |
| 운동 시간은 시계 하나(`elapsedRealtime`)로 (v2) | 앱 화면과 알림 시간이 1~2초 어긋나는 문제가 있었다. 휴대폰 시각을 바꿔도 흔들리지 않는 부팅 후 경과 시간 하나를 앱·알림·인터벌이 같이 쓰게 했다. |
| 강제 종료 대비 10초마다 중간 저장 (v2) | 휴대폰이 배터리 절약으로 앱을 끄면 기록이 통째로 사라졌다. 10초마다 중간 기록을 저장하고, 앱을 다시 열면 그 자리부터 이어서 기록한다. |
| 자동 업데이트는 SHA-256 확인 뒤 설치 화면만 (v2) | 친구들이 매번 Releases에 들어오지 않아도 되게 하되, 받은 파일이 진짜인지 확인하고 설치는 사용자가 직접 누르게 했다. Play 스토어 등록 때는 이 기능을 뺀다(스토어 정책). |
| 잠금 위 앱 화면은 기본 끔 (v2) | 잠금 화면 위에 달리기 화면을 띄우면 잠금이 풀린 것처럼 보여 다른 사람이 휴대폰을 만질 수 있다고 오해하기 쉽다. 기본은 알림 카드만, 원하는 사람만 켜게 했다. |
| 안드로이드 16 기준으로 빌드(targetSdk 36) (v2) | 안드로이드 16의 「실시간 알림」(상태 표시줄 칩)을 쓰려면 16 기준이어야 한다. 16 기준이 되면서 모든 화면이 상태 표시줄 뒤까지 그려지므로 화면마다 여백을 맞췄다. |
| 빌드는 GitHub Actions에서만 | 내 PC에 안드로이드 개발 도구를 깔지 않아도 되고, 누가 빌드해도 같은 결과가 나온다. 테스트를 통과해야 설치 파일이 만들어진다. v2부터 에뮬레이터(안드로이드 14·16) 화면 캡처와 시간·일시정지 점검도 자동으로 돈다. |
| 서명 키는 저장소에 넣지 않고 GitHub Secrets에만 | 키가 새면 다른 사람이 가짜 업데이트를 만들 수 있다. 공식 설치 파일은 Releases에서만 받게 하고 SHA-256 값을 함께 올린다. |

## 5. 확인 방법

- 로직(걷기·뛰기 구분, 거리·구간, GPS 흔들림 거르기, 걸음, 음성 안내, 인터벌, 자동 일시정지, 최고 기록, 중간 저장, 날씨, 업데이트 판단, GPX)은 단위 테스트로 확인하고, 테스트가 실패하면 설치 파일이 만들어지지 않는다.
- 빌드할 때마다 앱 권한 목록을 뽑아, 허용한 권한 밖의 것이 들어오면 빌드를 실패시킨다.
- 에뮬레이터에 가상 위치를 흘려 넣어 실제로 기록을 돌리고, 화면·잠금 화면·알림·일시정지·앱과 알림 시간 일치·종료 뒤 결과 화면·공유 이미지를 자동으로 찍어 확인한다(`ci-screens`, 안드로이드 16은 `ci-screens36`).
- 실제 GPS·음성·배터리·잠금 화면 동작은 휴대폰에서 직접 달리며 확인한다(테스트로 대신할 수 없음). 다른 앱과 숫자 비교 방법은 `docs/ACCURACY.md`.

## 6. 바꾼 기록

- v1 (2026-10-29): 처음 작성. 0.1을 만든 뒤 "다른 러닝 앱보다 조악하다"고 판단해, 0.2에서 다른 앱(나이키런클럽·스트라바·런키퍼·런데이)과 비교해 기능을 보강하기로 했다. 지도를 넣으면서 "인터넷 권한 없음" 원칙을 "기록은 보내지 않고, 인터넷은 지도 그림에만, 설정에서 끌 수 있게"로 바꿨다.
- v2 (2026-10-29): 0.3을 만들며 목표에 "삼성 헬스 수준의 정확도·잠금 화면"을 더했다. 휴대폰으로 직접 확인하며 나온 문제와 결정:
  - 앱과 알림의 초가 어긋남 → 시계를 하나로 통일. 일시정지 시간 계산이 틀어지는 버그와 멈춘 구간에 거리가 붙는 문제 → 수정.
  - 휴대폰이 앱을 강제로 꺼서 기록이 사라짐 → 10초 중간 저장과 이어서 기록.
  - 알림 「종료」 뒤 결과 화면이 안 열림 → 앱을 열어 끝내고 저장되는 대로 결과 화면을 열게 수정.
  - 상태 표시줄 초록 칩·나우 바를 넣으려 했으나, 안드로이드 16.0 정식판은 「실시간 알림」이 다른 앱에 열려 있지 않음을 에뮬레이터로 확인했고(권한 자체가 없어 항상 꺼짐), 나우 바는 삼성이 등록한 앱만 들어감을 휴대폰 설정에서 확인했다. 앱이 해결할 수 없는 부분이라, 칩은 휴대폰이 16 분기 업데이트를 받으면 자동으로 나오게 코드만 준비하고 마무리했다. 잠금 화면 카드가 안 보인 것은 휴대폰의 잠금화면 알림 스타일(아이콘) 때문이었고, 사용자 취향 설정이라 바꾸라고 강요하지 않고 안내만 했다.
  - 정확히 한 방향으로만 달린 기록에서 지도가 세계 지도처럼 넓게 보임 → 지도 맞춤에 최소 폭을 둬서 수정.
  - 인터넷 사용처가 날씨·업데이트 확인으로 늘어 개인정보 원칙을 "세 곳만, 각각 끌 수 있게"로 고쳤다.
